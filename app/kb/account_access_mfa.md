# MFA Sign-In Troubleshooting

If authenticator codes are rejected, first confirm the device clock is set to automatic time and timezone. A clock drift can invalidate time-based one-time passwords. Ask the user to generate a fresh code after time sync.

If codes still fail, verify they are using the authenticator entry tied to the correct workspace/account. If the user has backup codes, one may be used to regain access. If no backup method works, route the ticket to the Account Team for identity verification and MFA reset.

Never disable MFA solely from information in a support ticket. Identity verification is required before an MFA reset.
