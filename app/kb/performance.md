# Slow Dashboards and Performance Issues

For slowness, capture the affected page or workflow, approximate start time, user region, browser, and whether other users are affected. Ask the customer to compare an incognito session and another network when practical.

If multiple users experience severe latency or timeouts in a production workflow, route to Engineering with high priority. If the problem is isolated to one browser or local network and a workaround exists, normal support troubleshooting is appropriate.
